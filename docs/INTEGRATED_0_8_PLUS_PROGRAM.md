# KINLINK — INTEGRATED 0.8+ PROGRAM

This plan translates the full A+B+C specification into large internal waves. It exists specifically to prevent the old “small beta -> install -> small beta -> install” loop.

## Operating rule

Development can contain many internal commits and CI runs. **Human installation is not the unit of progress.** A field update happens only when a coherent batch closes its machine, visual, safety, signing, readback and field-plan gates.

Current full product maturity remains **44.8% across 80 macro capabilities**. B-depth growth does not change that denominator by itself.

## W0 — Truth + proof foundation

Status: mostly complete.

Scope: truthful QoE, no fake 100/100, secure delivery, memory/communication continuity, rendered UI proof, dead-end registry.

Exit: fresh exact-head rendered proof + manual semantic audit.

## W1 — Platform diagnostics + capability discovery

Status: active now.

Scope:
- callback/generation race safety;
- runtime capability inventory;
- Data Saver / Usage Access / Android 17 LAN-permission state;
- advanced-diagnostics eligibility;
- confidence/abstention;
- no unsupported platform claim.

This wave is what the current 0.8 branch is closing.

## W2 — Context + Mobile Vault core

Build the missing product economics/context layer:
- privacy-preserving trusted/home Wi-Fi memory;
- plan size and expiry;
- reserve / normal / rescue / critical envelopes;
- optional richer NetworkStats lane;
- multi-SIM-safe state;
- cost-aware policy inputs.

No paid-data probe is allowed to become a dependency.

## W3 — Complete product surfaces + diagnostics

Build the originally promised user product, not only the current cockpit:
- Diagnostic path;
- This week;
- Mobile Vault;
- Settings;
- Emergency;
- full diagnostic ZIP;
- energy/crash/failure-cluster summaries.

## W4 — Strong Stabilizer SHADOW / per-app canary

This is the major missing active-resilience subsystem.

It is not enabled whole-device by default. First:
- separate VpnService/TUN process;
- per-app canary;
- DNS resilience;
- LAN preservation;
- route/loop safety;
- MTU safety;
- meteredness;
- IPv4/IPv6/QUIC;
- immediate native-network escape.

Only measurable benefit can move it out of SHADOW.

## W5 — Personal Network Twin replay + learner

Build deterministic replay and champion/challenger evaluation before learned policies can influence autonomy.

## W6 — One coherent field candidate

Only after the integrated waves have enough closed evidence:
- one signed candidate;
- one Drive installer;
- one readback;
- one in-place update;
- field/resource qualification;
- canonical promotion only after proof.

## Anti-micro-beta invariant

A CI iteration is not a user beta. A commit is not a user beta. A screenshot matrix is not a user beta.

The user should not be asked to repeatedly install tiny increments. The installed 0.7.3 remains the baseline while the integrated successor advances internally.
